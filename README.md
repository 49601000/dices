# ダイスロールシミュレーター

ブラウザで動作するダイスロールシミュレーターです。

## 機能

- **ダイス表記対応**: `XdY` の形式でダイスを振ります
  - `X`: ダイス個数（1～100個）
  - `Y`: ダイスの面数（6～200面）
  
- **複数ダイス対応**: 1d6、2d10、3d20など、複数のダイスを一度に振れます

- **結果表示**: 各ダイスの出目と合計を表示します

## 使い方

1. **dice.html** をブラウザで開く
2. 入力フィールドにダイス表記を入力（例: `1d6`, `2d20`, `5d12`）
3. 「ロール」ボタンをクリック
4. 結果が表示されます

## 例

- `1d6`: 1個の6面ダイスを振る
- `2d10`: 2個の10面ダイスを振る
- `3d20`: 3個の20面ダイスを振る
- `1d100`: 1個の100面ダイスを振る
- `1d200`: 1個の200面ダイスを振る（最大面数）

## 対応環境

- Chrome、Firefox、Safari、Edge など、JavaScriptをサポートするモダンブラウザ
